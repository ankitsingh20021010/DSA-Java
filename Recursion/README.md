# Java Recursion Tasks

This repository contains beginner-friendly Java recursion problems. These tasks are designed to help understand the basics of recursion and improve problem-solving skills.

## 📋 Tasks

### Task 1: Print First N Natural Numbers
Print numbers from ⁠ 1 ⁠ to ⁠ N ⁠ using recursion.

### Task 2: Print Numbers from N to 1
Print numbers from ⁠ N ⁠ to ⁠ 1 ⁠ using recursion.

### Task 3: Sum of First N Natural Numbers
Find the sum of the first ⁠ N ⁠ natural numbers using recursion.

### Task 4: Factorial of a Number
Find the factorial of a given number using recursion.

### Task 5: Nth Fibonacci Number
Find the ⁠ Nth ⁠ Fibonacci number using recursion.

### Task 6: Fibonacci Series
Print the Fibonacci series up to ⁠ N ⁠ terms using recursion.

### Task 7: Power of a Number
Find ⁠ a^b ⁠ (power of a number) using recursion.

### Task 8: Count Digits
Count the total number of digits in a given number using recursion.

### Task 9: Reverse a Number
Reverse a given number using recursion.

### Task 10: Palindrome Number
Check whether a given number is a palindrome using recursion.
